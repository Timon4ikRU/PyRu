# PyRu - Русский Python

PyRu - экспериментальная библиотека с русскоязычными функциями для Python.

## Установка

```bash
git clone https://github.com/Timon4ikRU/PyRu.git
cd PyRu
```

## Использование

```python
from pyru import *

печатать("Привет, мир!")
числа = список([1, 2, 3, 4, 5])

for число in числа:
    печатать(число)

печатать("Сумма:", сумма(числа))
```
